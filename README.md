# 🎮 Крымский Мост 1v1 — Оператор FPV Дрона vs Водитель-Стрелок Бензовоза

**Настольная 3D-игра для ПК** (Windows / Linux / macOS). Не браузерная — это полноценное приложение с настоящим 3D-рендерингом, звуком и сетевым мультиплеером **1 на 1 по TCP**.

| Роль | Цель | Вооружение |
|---|---|---|
| 🛸 **Оператор FPV Дрона** (Игрок 1) | Уничтожить бензовоз с воздуха | Кумулятивная БЧ (ПГ-7ВЛ), форсаж, сброс БЧ |
| 🚛 **Водитель-Стрелок Бензовоза** (Игрок 2) | Проехать мост живым и **сбить FPV-дрон** | Зенитная турель, антидроновый дробовик, РЭБ «Купол-М», дым |

### 🎯 Как забить цель (главная механика оператора)
* **Дистанционный подрыв БЧ** (`ПКМ` / `Space` / `RT`): оператор сбрасывает боезаряд — **FPV остаётся в строю** и может сразу уходить на второй заход. БЧ перезаряжается 2.5 с. Если заряд не достал до цистерны — он срывается вхолостую (урон 0), так что подрывать надо точно.
* **Таран (камикадзе)**: если влететь в цистерну или в конструкцию моста — дрон теряется, но удар наносит максимальный урон.
* Цистерне нужно **2 попадания** (100 HP, одно попадание — 62 HP), поэтому за раунд обычно требуется 2-3 захода.
* Бензовоз в ответ **сбивает FPV**: зенитная турель (дальность 170 м), антидроновый дробовик (95 м), РЭБ глушит видеоканал, дым прячет дрон. Чтобы попасть, турели нужно **удержать цель в ретикле ~0.8 с** (кольцо «ЗАХВАТ ЦЕЛИ!»), так что дрон может уклоняться и вырываться из-под огня.

## 🚀 Быстрый старт

### Windows
1. Установите **Python 3.10+** ([python.org](https://www.python.org/downloads/), при установке поставьте галочку *Add Python to PATH*).
2. Склонируйте репозиторий и запустите двойным кликом **`run_windows.bat`** — скрипт сам создаст виртуальное окружение `.venv` и поставит библиотеки.
3. Откроется 3D-окно игры с главным меню.

> ⚠️ **Важно про ZIP-архив:** скачанный ZIP нужно сначала **распаковать** в отдельную папку, и запускать `run_windows.bat` уже из неё. Запуск прямо из архива (или из папки `Downloads` без распаковки) ломает пути и виртуальное окружение.
> Все `.bat`-файлы в репозитории сохранены с Windows-переводами строк (CRLF) и только в ASCII-кодировке — поэтому `cmd.exe` читает их корректно на любой версии Windows и с любой кодовой страницей.

### Linux / macOS
```bash
git clone https://github.com/awdawdwdawd131a/game.git
cd game
chmod +x run_linux_mac.sh
./run_linux_mac.sh
```

### Готовый `.exe` без Python у друга
Запустите на Windows **`build_exe_windows.bat`** → в папке `dist/` появится `CrimeanBridge1v1.exe`. Скопируйте папку `dist` другу — Python ему больше не нужен.
Для отладки соберите вариант с видимой консолью: **`build_exe_windows.bat debug`** → `dist\CrimeanBridge1v1-debug.exe`.

## 🩺 Если окно закрылось сразу / ничего не запускается

Игра **никогда не закрывает окно консоли молча**: лаунчер всегда ставит `pause` в конце, а сама игра пишет подробный отчёт об ошибке. Что делать:

| Симптом | Что значит | Что делать |
|---|---|---|
| Окно консоли мигнуло и пропало, ошибок не видно | Ошибка при запуске, окно было закрыто старой версией лаунчера | Скачать новую версию репозитория (или `git pull`), запустить `run_windows.bat` **в открытом окне cmd** — тогда ошибка останется на экране |
| В окне `The system cannot find the path specified` и куски команд вида `'grade'`, `'equirements.txt'` | Файл `.bat` скачался с Unix-переводами строк (LF) — `cmd.exe` не смог разобрать блок | Скачать репозиторий **свежим ZIP** (в нём уже CRLF) или выполнить `git pull` |
| `[ERROR] Python 3.10+ was not found on this PC` | Python не установлен или не прописан в PATH | Установить Python с python.org с галочкой *Add python.exe to PATH*, затем запустить `.bat` снова |
| `[ERROR] Installation of the libraries failed` | Нет интернета / прокси / вирусник съел `pip` | Проверить интернет, повторить запуск; при корпоративной сети — указать прокси: `pip install -r requirements.txt --proxy http://user:pass@host:port` |
| Игра запустилась, но сразу вылетела | Сбой в игре | Открыть файл **`logs\crash.log`** — там полный текст ошибки. Переслать его разработчику |
| `.exe` запускается и сразу закрывается | Сбой при старке собранной версии | Рядом с `.exe` появится `logs\crash.log` с причиной. Либо соберите вариант с консолью: `build_exe_windows.bat debug` |

Полезно знать:
* `logs\last_run.log` — полный лог последнего запуска (что писала игра в консоль).
* `logs\crash.log` — отчёт о последнем падении (с текстом ошибки и стеком).
* Быстрая проверка «жив ли Python»: `run_windows.bat --self-test` — выведет отчёт из 9 автотестов прямо в консоли.

## 🕹️ Управление

### 🛸 Оператор FPV-дрона
| Действие | Клавиатура + мышь | Геймпад (Xbox / DualSense) | FPV-пульт (Mode 2, USB) |
|---|---|---|---|
| Газ / Тяга вверх | `Shift` / `E` | RT / LT | Ось 2 (Throttle) |
| Тяга вниз | `Ctrl` / `C` | LT | Ось 2 (Throttle) |
| Вперёд / Назад | `W` / `S` | Левый стик Y | Ось 1 (Pitch) |
| Влево / Вправо (ролл) | `A` / `D` | Левый стик X | Ось 0 (Roll) |
| Обзор (рыск/тангаж) | Мышь | Правый стик | Ось 3 (Yaw) + ручка переключения канала |
| Форсаж | `F` / ЛКМ | LB (кнопка 4) | Кнопка SA / SB |
| **Сброс боезаряда (дистанционный подрыв БЧ)** | **ПКМ** / `Space` | RT / R2 | Кнопка SD / SA |
| Режим полёта: Стабилизация ↔ **Акро** | `X` | LT (кнопка 6) | Кнопка SA (долгое) |
| Переключить режим **FPV-пульта Mode 2** | `M` | — | — |
| Готовность (в меню модификаторов) | `Enter` / `R` | A | SA |

### 🚛 Водитель бензовоза
| Действие | Клавиатура + мышь | Геймпад |
|---|---|---|
| Газ / Тормоз | `W` / `S` | Левый стик Y или RT/LT |
| Руль | `A` / `D` | Левый стик X |
| Прицеливание зенитной турели (360°) | Мышь | Правый стик |
| **Огонь зенитной турели** | **ЛКМ** / `Space` | RT / RB |
| **Антидроновый дробовик (сбить FPV)** | **ПКМ** | LT / LB |
| **Включить РЭБ «Купол-М»** | `E` | Кнопка X |
| **Дымовая завеса** | `Q` | Кнопка B |
| Выбор модификатора в окне драфта | `1` … `5` | D-pad / стик |

> **Пауза / выход:** `Esc`. **Смена раунда:** оба игрока жмут `Enter` / `R` в окне выбора модификатора.

## 🌦 Погода — новая каждый раунд

6 погодных пресетов, которые сменяются **по кругу без повторов** (мешок + перетасовка):

1. ☀️ **Ясный крымский полдень** — идеальная видимость, максимальный заряд батареи.
2. 🌫 **Густой керченский туман** — сильно падает видимость, опасно для пилотажных ориентиров.
3. ⛈ **Черноморский шторм и гроза** — порывы ветра раскачивают дрон, дождь, риск пробоя.
4. 🌇 **Багровый закат и боковой шквал** — боковой ветер сносит дрон, низкий контраст.
5. 🌙 **Ночная тревога (прожекторы)** — темнота, работают только прожекторы и ИК-тепловизор.
6. ❄️ **Ледяной норд-ост (бора)** — гололёд, худшее сцепление дороги, аккумулятор садится быстрее.

Каждая погода меняет: **видимость (дальность обнаружения)**, **ветер/турбулентность**, **сцепление с дорогой** (у бензовоза) и **расход батареи** (у дрона).

Каждый игрок перед раундом выбирает **1 модификатор из 5** (клавиши `1`…`5`). Модификаторы противника **известны** — можно играть встречно.

## 🌐 Сетевой мультиплеер 1 на 1

* **Хост**: главное меню → «Создать сервер 1 на 1 (Хост для игры с другом)» → выбрать роль (`F1`/`F2`) → `Enter`.
* **Клиент**: главное меню → «Подключиться к серверу по IP (Второй ПК)» → ввести IP и порт `27015` → выбрать свободную роль → `Enter`.
* **Выделенный сервер** (для VPS, работает 24/7 без графики):
  ```bash
  python main.py --server --port 27015            # чистый сервер
  python main.py --server --port 27015 --bot-fill # пустой слот занимает ИИ-бот
  ```

### 👉 **Полная пошаговая инструкция по хостингу (LAN, Radmin VPN, ZeroTier, проброс портов, playit.gg, VPS)** — в отдельном файле: **[`HOSTING_RU.md`](HOSTING_RU.md)**

## 🧪 Проверочный режим (диагностика работоспособности)

Запустить **внутри игры**: главное меню → «**Проверочный режим (Автотесты + 3D Демо Сплит-Скрин)**».
Откроется 3D-сплит-скрин (слева камера FPV, справа камера ПВО бензовоза) и живой отчёт по проверкам.
Клавиша `W` в этом режиме мгновенно переключает погоду — удобно проверять рендер.

Запустить **через терминал** (годится для CI и быстрой диагностики):
```bash
python main.py --self-test
```
или с выгрузкой 3D-скриншотов:
```bash
python main.py --self-test --save-test-frames test_output
```

### Что проверяет автотест (9 пунктов)
1. 📁 **Сохранность картинки `черешня.jpg`** в репозитории (файл не удаляется и не перезаписывается — это «пасхалка» на приборной панели).
2. 🧱 **3D-движок**: рендер сцен моста, камер, моделей FPV/бензовоза и HUD.
3. 🌦 **Смена погоды**: все 6 режимов сменяются каждый раунд без повторов.
4. 🧬 **Модификаторы**: 5+5 модификаторов, включая пару «Оптоволокно vs РЭБ».
5. 💥 **Сбитие FPV**: бензовоз реально сбивает дрон зенитной турелью и дробовиком.
6. 🔥 **Взрыв бензовоза**: удар FPV уничтожает цистерну и приносит победу оператору.
7. 🌐 **Сетевой 1v1**: поднимается реальный TCP-сервер, подключаются 2 клиента, проверяется синхронизация и пинг.
8. 🎮 **Джойстики**: инициализируется SDL2-слой joystick (геймпад и FPV-пульт).
9. 💣 **БЧ и захват цели**: проверяется, что дистанционный подрыв не убивает FPV, точный сброс наносит урон, а ПВО наводится только при удержании цели в ретикле.

## 🧰 Требования и зависимости

* **Python 3.10+**
* `pygame-ce` — окно, ввод, звук, джойстики (SDL2)
* `numpy` — физика, 3D-математика, рендер, синтез звука
* `pillow` — загрузка/масштабирование картинок (пасхалка)
* `pyinstaller` — сборка `.exe` (нужен только при сборке)
* Видеокарта **не обязательна**: есть программный 3D-рендер на NumPy, который работает даже на старых ПК и в виртуальных машинах.

Установка вручную:
```bash
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt     # Windows
.venv/bin/pip install -r requirements.txt        # Linux / macOS
```
