# Инструкция: Как захостить и играть 1 на 1 на разных компьютерах

Игра **«Крымский Мост 1v1: Оператор FPV Дрона vs Водитель-Стрелок Бензовоза»** — это полноценное **настольное приложение для ПК** (Windows / Linux / macOS) с прямым сетевым протоколом TCP и низкой задержкой (`TCP_NODELAY`, порт по умолчанию `27015`).

> **Главное (новое):** больше не нужно ни Radmin VPN, ни playit.gg, ни ручного
> проброса портов. Игра сама, автоматически:
> 1. пытается открыть порт на вашем роутере (UPnP) и узнать ваш публичный IP;
> 2. если провайдер «серый» (CGNAT) или UPnP выключен — поднимает
>    **бесплатный TCP-туннель** (без регистрации и без премиума);
> 3. показывает **готовый адрес**, который нужно просто отправить другу.

---

## 🚀 Способ 0 (рекомендуемый): два готовых .exe, всё автоматически

Это то, что нужно вам и вашему другу. Никаких папок проекта, никакого Python.

### Что отправить другу

**ОДИН файл — `CrimeanBridge1v1.exe`.** Больше ничего: ни папок, ни `requirements.txt`,
ни распаковки архивов. Друг скачивает файл, кладёт куда угодно (например, на рабочий
стол) и дважды кликает.

> Если антивирус ругается на файл — это нормальная реакция на любой
> «неподписанный» .exe. Добавьте файл в исключения или нажмите
> «Подробнее» → «Выполнить в любом случае». Файл собран на чистой
> Windows-машине в CI и не содержит ничего вредоносного.

### Что запустить у себя (хост)

**`CrimeanBridge1v1-Server.exe`** — отдельный выделенный сервер с видимой консолью
(в консоли печатается всё, что происходит, и **готовый адрес для друга**).
Можно просто запустить и игру обычным способом — тогда сервер поднимается
внутри игры, а адрес будет показан панелью в углу экрана.

### Порядок действий

1. **Хост:** запустите `CrimeanBridge1v1-Server.exe` (или запустите игру и выберите
   «Создать сервер 1 на 1»). Сервер слушает порт `27015`.
2. **Хост:** через несколько секунд в консоли (или в панели в углу игры) появится
   готовый адрес, например:
   ```
    ГОТОВЫЙ АДРЕС ДЛЯ ДРУГА (скопируйте ему):
       -> 203.0.113.45:27015          (Прямое подключение (UPnP))
       -> bore.pub:49152              (Бесплатный туннель (bore.pub))
   ```
   Первый адрес — прямой (быстрее). Второй — запасной, он работает, даже если
   у провайдера «серый» IP. **Можно отправить другу любой из них** (лучше оба).
3. **Друг:** запускает `CrimeanBridge1v1.exe` → «Подключиться к серверу по IP» →
   вставляет полученный адрес **целиком** (например `bore.pub:49152` — порт
   можно вписать вместе с адресом, отдельное поле «порт» тогда не нужно) →
   выбирает свободную роль (`F1` — Оператор FPV Дрона, `F2` — Водитель Бензовоза) →
   **ENTER**.
4. Окно подключения теперь **не зависает**: пока идёт соединение, показывается
   экран «ПОДКЛЮЧЕНИЕ…» с анимацией и секундомером. Если что-то пошло не так —
   появится понятная ошибка, а не «зависшее окно». Отменить попытку — **ESC**.
5. Оба игрока жмут **ENTER** в меню модификаторов — начинается 1-й раунд.

### Собираем .exe сами (если хотите пересобрать)

Двойной клик по **`build_exe_windows.bat`** на Windows. Скрипт сам создаст `.venv`,
поставит зависимости и соберёт **два** файла в папке `dist/`:

| Файл | Кому | Что делает |
|---|---|---|
| `CrimeanBridge1v1.exe` | **другу** | сама игра (окно, без консоли) |
| `CrimeanBridge1v1-Server.exe` | **себе** | выделенный сервер с консолью |

Все звуки и картинки встроены **внутрь** .exe — рядом с ним ничего не нужно.

### Сборка .exe без установки Python (в GitHub)

Если на вашем Windows нет Python, готовые файлы собираются автоматически в CI:
вкладка **Actions** → **Build Windows EXE** → зелёная галочка → **Artifacts** →
`CrimeanBridge1v1-Windows`. Либо просто заберите готовый `.exe` из релизов репозитория.

## 🛠 Автоматическая настройка доступа: как это работает

`src/net_setup.py` выполняет две стратегии по порядку:

1. **UPnP / IGD.** Игра ищет в локальной сети домашний роутер (SSDP), читает его
   описание и командой `AddPortMapping` пробрасывает TCP-порт `27015` наружу.
   Затем определяет ваш публичный IP и сравнивает его с WAN-адресом роутера —
   так распознаётся **CGNAT** («серый» IP у провайдера).
   *Если* UPnP разрешён и CGNAT нет — друг подключается напрямую по вашему
   публичному IP. Никаких сторонних сервисов.

2. **Бесплатный туннель (bore.pub).** Если UPnP не сработал (роутер выключил
   UPnP, или провайдер использует CGNAT) — игра поднимает **бесплатный**
   TCP-туннель на `bore.pub`. Регистрация не нужна, премиум не нужен, это
   открытый протокол. Реализация туннеля целиком на Python внутри игры, поэтому
   **другу по-прежнему нужен только один .exe** — никаких дополнительных программ.
   Публичный адрес выглядит как `bore.pub:49152`.

Обе стратегии выполняются **в фоновом потоке**: интерфейс игры никогда не
подвисает. Панель в левом нижнем углу матча показывает все найденные адреса и
статус настройки.

Отключить автоматическую настройку (например, для теста в локальной сети):
```bash
python main.py --server --port 27015 --no-auto-net
```

## Способ 1: В одной локальной сети (Домашний Wi-Fi / LAN-кабель)

Если оба ПК подключены к одному роутеру — это самый быстрый вариант, интернет
и внешние сервисы вообще не нужны.

1. **Хост:** игра → «Создать сервер 1 на 1 (Хост)» → на экране сразу видны
   локальные адреса (например `192.168.1.45:27015`) → **ENTER**.
2. **Друг:** игра → «Подключиться к серверу по IP» → введите `192.168.1.45:27015`
   (можно целиком, с портом) → **ENTER**.

> **Если не подключается в Windows:** откройте PowerShell от имени Администратора
> на ПК Хоста и разрешите входящий порт `27015` одной командой:
> ```powershell
> New-NetFirewallRule -DisplayName "CrimeanBridge1v1" -Direction Inbound -Protocol TCP -LocalPort 27015 -Action Allow
> ```

## Способ 2: Выделенный сервер на VPS / VDS (Ubuntu / Debian Linux)

Если нужен постоянный публичный сервер, к которому оба игрока подключаются по
белому IP (сервер живёт 24/7, даже когда вы выключили домашний ПК):

1. Зайдите по SSH на ваш Linux VPS:
   ```bash
   sudo apt update && sudo apt install -y git python3 python3-venv
   git clone https://github.com/awdawdwdawd131a/game.git
   cd game
   chmod +x run_linux_mac.sh host_server_linux.sh
   ```
2. Откройте порт в файрволе сервера:
   ```bash
   sudo ufw allow 27015/tcp
   ```
3. Запустите headless-сервер:
   ```bash
   ./host_server_linux.sh 27015
   ```
   *(Чтобы сервер работал после закрытия SSH — запустите в `tmux`, `screen` или через `systemd`.)*
4. Оба игрока выбирают «Подключиться к серверу по IP» и вводят публичный IP VPS
   и порт `27015`.

## Способ 3 (запасной): Radmin VPN / ZeroTier / Tailscale

Если у вас **работает** Radmin VPN (у некоторых провайдеров он не поднимается) —
подойдёт и он:

1. Установите Radmin VPN на оба ПК, создайте сеть на Хосте, подключитесь к ней
   на клиенте.
2. Узнайте адрес Хоста в Radmin (обычно `26.x.x.x`).
3. Хост: игра → «Создать сервер 1 на 1» → ENTER.
4. Друг: игра → «Подключиться к серверу по IP» → `26.x.x.x` → ENTER.

> `playit.gg` в базовом виде не подходит: нужный функционал там платный.
> Если он у вас уже работает и устраивает — можно пользоваться и им (туннель
> должен быть именно **TCP** на порт `27015`), но он больше не нужен: встроенный
> туннель делает то же самое бесплатно и без установки чего-либо.

## 🩺 Если что-то не работает

| Симптом | Причина и что делать |
|---|---|
| Друг вводит адрес, пишет «Не удалось подключиться» | Проверьте, что сервер на Хосте **запущен** и ждёт. Если у Хоста несколько адресов — попробуйте другой (в панели в углу показаны все). |
| Окно подключения «висит» | Больше не должно: соединение идёт в фоне, показывается экран ожидания. Если видно экран ожидания более 12 секунд — вернитесь назад (ESC) и проверьте адрес/порт. |
| «Роли заняты» | Второй игрок выбрал ту же роль, что и первый. Первый — `F1` (FPV Дрон), второй — `F2` (Бензовоз). |
| Не открывается порт на роутере | У части роутеров UPnP выключен — включите «UPnP» в настройках роутера, либо просто используйте адрес бесплатного туннеля (он работает всегда). |
| Хост выключил ПК — другая сторона отвалилась | Это ожидаемо: сервер живёт на ПК Хоста. Для постоянной игры используйте VPS (способ 2). |
| В поле «IP» не принимается адрес с буквами | Теперь можно вписать адрес **целиком с портом**: `bore.pub:49152` или `203.0.113.45:27015`. |

## Как запустить Проверочный режим (Диагностика работоспособности)

1. **Внутри игры:** главное меню → **«Проверочный режим (Автотесты + 3D Демо Сплит-Скрин)»**
   (или `python main.py --verify`). Экран разделится пополам и выведет отчёт по
   автоматическим проверкам. Нажимайте `W` для мгновенной смены погоды.
2. **Через командную строку:**
   ```bash
   python main.py --self-test
   ```
3. **Проверка сетевой части (туннель, UPnP, подключение):**
   ```bash
   python tools/test_bore_tunnel.py   # протокол бесплатного туннеля
   python tools/test_upnp.py          # проброс порта на роутере
   python tools/test_net_e2e.py       # сервер + туннель + клиент
   python tools/test_gui_connect.py   # окно не зависает при подключении
   ```
