# Инструкция: Как захостить и играть 1 на 1 на разных компьютерах

Игра **«Крымский Мост 1v1: Оператор FPV Дрона vs Водитель-Стрелок Бензовоза»** — это полноценное **настольное приложение для ПК** (Windows / Linux / macOS), использующее прямой сетевой протокол TCP с низкой задержкой (`TCP_NODELAY`, порт по умолчанию `27015`).

Ниже приведены **4 способа захостить игру** для игры с другом с двух разных компьютеров — от самого простого (за 1 минуту без настройки роутера) до выделенного круглосуточного VPS-сервера.

---

## Подготовка на обоих компьютерах

### Вариант А — Быстрый запуск через скрипт (Python 3.10+)
1. Скачайте / клонируйте репозиторий `game` на оба ПК:
   ```bash
   git clone https://github.com/awdawdwdawd131a/game.git
   cd game
   ```
   > ⚠️ Если вы качаете **ZIP-архив**, его нужно обязательно **распаковать** в отдельную папку и запускать `run_windows.bat` уже из распакованной папки. Все `.bat`-файлы в репозитории сохранены с Windows-переводами строк (CRLF) и в ASCII-кодировке, поэтому `cmd.exe` читает их корректно на любой Windows.
2. Запустите:
   - На **Windows**: двойной клик по `run_windows.bat` (скрипт сам создаст `.venv` и поставит `pygame-ce` и `numpy`). В конце работы окно **не закроется само** — будет ждать нажатия Enter, а все сообщения игры дополнительно пишутся в `logs\last_run.log`.
   - На **Linux / macOS**:
     ```bash
     chmod +x run_linux_mac.sh
     ./run_linux_mac.sh
     ```

> **Если окно консоли закрылось сразу** — откройте `cmd` в папке игры и запустите `run_windows.bat` из него: тогда текст ошибки останется на экране. Подробная таблица всех типовых сбоев и что делать — в разделе «🩺 Если окно закрылось сразу» файла `README.md`.

### Вариант Б — Сборка готового `.exe` без установки Python у второго игрока
Если у друга нет Python, соберите автономный `.exe` на своём Windows-ПК одним кликом по **`build_exe_windows.bat`**.
В папке `dist/` появится готовый `CrimeanBridge1v1.exe` — просто перешлите папку `dist` другу в Telegram / Discord / на флешке!
(Для отладки: `build_exe_windows.bat debug` соберёт вариант `CrimeanBridge1v1-debug.exe` с видимой консолью.)

## Способ 1: Через интернет с помощью Radmin VPN или ZeroTier (Самый простой — без проброса портов!)

Идеально подходит, если вы находитесь в разных городах или у провайдера «серый» IP (CGNAT):

1. Установите бесплатный **[Radmin VPN](https://www.radmin-vpn.com/ru/)** (или **ZeroTier / Tailscale**) на оба компьютера.
2. **Игрок 1 (Хост)** в Radmin VPN нажимает **«Сеть -> Создать новую сеть»**, придумывает имя и пароль.
3. **Игрок 2** в Radmin VPN нажимает **«Сеть -> Подключиться к существующей сети»** и вводит имя и пароль.
4. Посмотрите виртуальный IP-адрес Игрока 1 в окне Radmin VPN (обычно вида `26.x.x.x` — клик правой кнопкой -> «Скопировать IP-адрес»).
5. **На ПК Игрока 1 (Хост):**
   - Откройте игру -> выберите **«Создать сервер 1 на 1 (Хост для игры с другом)»**.
   - Выберите свою роль (`F1` — Оператор FPV Дрона, `F2` — Водитель Бензовоза).
   - Оставьте порт `27015` и нажмите **ENTER**.
   - *(При первом появлении окна Брандмауэра Windows нажмите «Разрешить доступ» для частных и публичных сетей).*
6. **На ПК Игрока 2 (Клиент):**
   - Откройте игру -> выберите **«Подключиться к серверу по IP (Второй ПК)»**.
   - Введите скопированный IP Хоста (`26.x.x.x`), порт `27015`, выберите свободную роль (`F1`/`F2`) и нажмите **ENTER**.
7. Как только оба игрока нажмут **ENTER / R / кнопку A** в меню выбора модификаторов — начнётся 1-й раунд!

## Способ 2: В одной локальной сети (Домашний Wi-Fi / LAN-кабель / Клуб)

Если оба ПК подключены к одному роутеру:

1. **Игрок 1** открывает игру -> **«Создать сервер 1 на 1 (Хост)»**. На экране сверху сразу отображается ваш локальный IP (например `192.168.1.45`). Нажмите **ENTER**.
2. **Игрок 2** открывает игру -> **«Подключиться к серверу по IP»**, вводит `192.168.1.45` и порт `27015`, жмёт **ENTER**.

> **Если не подключается в Windows:** откройте PowerShell от имени Администратора на ПК Хоста и разрешите входящий порт `27015` одной командой:
> ```powershell
> New-NetFirewallRule -DisplayName "CrimeanBridge1v1" -Direction Inbound -Protocol TCP -LocalPort 27015 -Action Allow
> ```

## Способ 3: Выделенный сервер на VPS / VDS (Ubuntu / Debian Linux)

Если вы хотите поднять постоянный публичный сервер в облаке, к которому оба игрока подключаются по белому IP:

1. Зайдите по SSH на ваш Linux VPS и выполните:
   ```bash
   sudo apt update && sudo apt install -y git python3 python3-venv
   git clone https://github.com/awdawdwdawd131a/game.git
   cd game
   chmod +x run_linux_mac.sh host_server_linux.sh
   ```
2. Откройте TCP-порт `27015` в файрволе сервера:
   ```bash
   sudo ufw allow 27015/tcp
   ```
3. Запустите выделенный headless-сервер (он не требует видеокарты или монитора!):
   ```bash
   ./host_server_linux.sh 27015
   ```
   *(Чтобы сервер работал 24/7 после закрытия SSH, запустите его в `tmux`, `screen` или через `systemd`).*
   Хотите потренироваться на сервере в одиночку, пока друг ещё не зашёл? Добавьте флаг `--bot-fill`:
   ```bash
   ./run_linux_mac.sh --server --port 27015 --bot-fill
   ```
4. Теперь **оба игрока** у себя на ПК выбирают в меню **«Подключиться к серверу по IP»**, вводят публичный IP вашего VPS и порт `27015` (один выбирает `F1` — FPV Дрон, второй `F2` — Бензовоз).

## Способ 4: Прямой хостинг через проброс порта на роутере (Port Forwarding) или `playit.gg`

- **Через роутер (если у Хоста «белый» внешний IP):** зайдите в настройки роутера (`192.168.1.1` / `192.168.0.1`), раздел *Переадресация портов / Виртуальные серверы (Port Forwarding)*, добавьте правило:
  - Протокол: `TCP`
  - Внешний порт: `27015` -> Внутренний порт: `27015`
  - Внутренний IP: локальный IP ПК Хоста (`192.168.x.x`)
  - Сообщите другу свой внешний IP (узнать можно на 2ip.ru).
- **Через бесплатный туннель `playit.gg` (если нет белого IP и не хочется ставить VPN другу):**
  1. Хост запускает сервер в игре на порту `27015`.
  2. Хост запускает клиент [playit.gg](https://playit.gg) и создаёт `Custom TCP Tunnel` на `127.0.0.1:27015`.
  3. Playit выдаёт публичный адрес вида `xxx.gl.at.ply.gg:49123` — друг просто вводит этот хост и порт в меню **«Подключиться к серверу по IP»**!

## Как запустить Проверочный режим (Диагностика работоспособности)

Чтобы перед игрой убедиться, что 3D-графика, смена погоды, модификаторы, сбитие дрона, сетевой стек и джойстик работают идеально:

1. **Внутри игры (с визуальным 3D Сплит-Скрином):**
   В главном меню выберите пункт **«Проверочный режим (Автотесты + 3D Демо Сплит-Скрин)»** (или запустите `python main.py --verify`).
   Экран разделится пополам (слева камера FPV, справа камера ПВО Бензовоза) и одновременно выведет отчёт по 9 автоматическим проверкам. Нажимайте `W` для мгновенного переключения погоды!
2. **Быстрая проверка через терминал / командную строку:**
   ```bash
   python main.py --self-test
   ```
   Выполнит все 9 проверок (включая поднятие реального локального TCP-сервера с двумя клиентами) за ~1 секунду и выведет отчёт `[ OK ]`.
